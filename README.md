# UAV path planning terrain

A browser-based terrain viewer with offline support. Open `index.html` directly in a browser. No UAV simulator, server, or account is needed to view a GeoTIFF.

## 使用

双击 `index.html`，点击“打开本地 GeoTIFF / JSON”选择高程文件。二维图滚轮/拖框放大，三维拖动旋转。读取发生在浏览器本地，不上传文件。源码版首次加载需要联网获取固定版本绘图库；完整离线使用可先运行 `python tools/download_vendor.py`，之后查看无需Python或网络。

GeoTIFF先显示源文件**完整范围**；二维放大后从原文件重新读取局部细节，不导出裁剪文件。三维使用覆盖全范围的概览网格；缺测像元保持空白。GeoTIFF的高程单位沿用源文件，未核实的单位不会自动当成米。

内置示例是明确标注的合成地形。公开代码包不附带论文实验数据、模型、飞行记录或许可尚未核实的第三方地形。实际地形产品的许可与本项目代码许可分别适用。

## GitHub Pages

把仓库的 `main` 分支根目录设为 Pages 发布源即可。页面使用相对路径，兼容项目站点子路径。绘图库优先使用本地副本，缺失时才从固定版本的公开CDN加载。

## 数据格式

可导入JSON：`{ "title": "地图名", "x": [0,1], "y": [1,0], "z": [[10,null],[11,12]], "source": "来源", "scope": "覆盖范围说明" }`。`z`按行对应`y`，缺测用`null`。坐标必须有限，所有行列尺寸一致。
