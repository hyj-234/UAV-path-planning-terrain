# UAV path planning terrain

A browser-based terrain viewer with offline support. Open `index.html` directly in a browser. No UAV simulator, server, or account is needed to view a GeoTIFF.

## 使用

双击 `index.html`，点击“打开本地 GeoTIFF / JSON”选择高程文件。二维图滚轮/拖框放大，三维拖动旋转。读取发生在浏览器本地，不上传文件。源码版首次加载需要联网获取固定版本绘图库；完整离线使用可先运行 `python tools/download_vendor.py`，之后查看无需Python或网络。

GeoTIFF先显示源文件**完整范围**；二维放大后从原文件重新读取局部细节，不导出裁剪文件。三维使用覆盖全范围的概览网格；缺测像元保持空白。GeoTIFF的高程单位沿用源文件，未核实的单位不会自动当成米。

现已扩充至**100个登记地点、20个国家、200份完整分发栅格**。32个瑞士精细地点有DTM/DSM；68个国际区域地点有相关的GLO30/GLO90。两种分辨率同源，不算成额外地点或独立观测。场景包括城市、山地、农村、森林、水域、荒漠、海岸和冰雪。

高分辨率192个固定诊断任务169个通过原始像元净空与简化点质量参考检查，23个达到搜索预算。区域级204条直线参考143条满足所声明表面净空与高度上限，61条超过高度上限。它们都不构成真实飞行安全认证；区域数据不适合精密低空/建筑间隙避障。DTM也不包含建筑、树冠。

100个地点进行了WorldCover锚点邻域辅助核对：76个获模型支持，24个混合或需复核；不宣称地类人工真值。源码、校验值、许可、限制和复现方法见[数据说明](dataset/README_CN.md)。官方原始文件约2.89GB，存于本地/官方源，未重复塞进Git仓库。

## 真实建筑与桥下三维增强

### 地形与推荐起终点

本项目提供完整真实场景，并为测试通过的配置提供推荐起点和终点，方便使用者直接开展路径规划研究。推荐点附地图版本、坐标单位、飞机尺寸、净空/间距、测试条件及验证结果，适用范围以该记录为准。使用者可以采用推荐点，也可以自行选择端点、调整参数或设计其他任务。

推荐端点按实际通过的检查分级说明：局部几何初筛、端点角色核验、完整连接轨迹验证。单点通过不自动表示点对连通。当前6个综合几何初筛通过点列为推荐候选，其起降角色与完整航线尚未验证；现有30个合成校准任务另有明确标识。详情及候选坐标见[端点核验说明](precision3d/真实起飞悬停降落点核验_CN.md)和[全部初筛记录](precision3d/endpoint_validation/endpoint_screening.json)。

后续扩展采用[针对性定位与数据纳入规则](precision3d/针对性定位与数据纳入规则_CN.md)：优先真实分层通道、细小结构、观测缺失和多机等待占位。已筛出32个FRACTAL训练侧元数据候选，尚未下载其点云、未增加合格规划场景；SemanticBridge保留CC BY-NC数据条款的核验边界。新增数据数量不作为主要创新。

[地图尺度与任务包设计](precision3d/地图尺度与任务包设计_CN.md)说明无人机体积、净空余量、局部米制坐标以及固定起终点的交付要求，区分可执行合成校准任务与尚未核验的真实端点。

[三维查看器](precision3d/index.html)新增瑞士完整分类点云与实际建筑模型、伯明翰运河桥实测TLS。完整六份原件约1.82GB，均核对发布方SHA-256，保留在本地/官方源；网页为完整范围的抽样派生。三维增强只有两个来源区域，相关版本不算独立场景。建筑、桥面、桥墩/拉索与未知空间分开。

[使用说明](precision3d/README_CN.md)、[统一多机评测规范v0.1](precision3d/统一多无人机路径规划基准规范_CN.md)、[创新定位与既有基准对照](precision3d/创新点与现有基准对照_CN.md)。附30个合成协议校准任务、三种启发式90条记录和连续检查器；真实桥下航线资格数量目前为0，尚非完整实飞认证基准。许可分别保留swisstopo OGD与Fang等的CC BY 4.0，不能套用代码MIT许可。

## GitHub Pages

把仓库的 `main` 分支根目录设为 Pages 发布源即可。页面使用相对路径，兼容项目站点子路径。绘图库优先使用本地副本，缺失时才从固定版本的公开CDN加载。

## 数据格式

可导入JSON：`{ "title": "地图名", "x": [0,1], "y": [1,0], "z": [[10,null],[11,12]], "source": "来源", "scope": "覆盖范围说明" }`。`z`按行对应`y`，缺测用`null`。坐标必须有限，所有行列尺寸一致。
